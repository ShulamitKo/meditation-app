# 🧘 מחולל מדיטציות אישיות

אפליקציית ווב ליצירת מדיטציות מודרכות מותאמות אישית בעברית — טקסט שנכתב ב-AI, ודיבוב קולי טבעי.

**דמו חי:** [meditation-generator.vercel.app](https://meditation-generator.vercel.app) *(מוגן בסיסמה)*

---

## ✨ תכונות

- 🎯 **6 סוגי מדיטציה** — הרפיה, שינה, מיקוד, ריפוי רגשי, אהבה עצמית, ונושא חופשי
- ⏱️ **בחירת משך** — 3 או 5 דקות (הטקסט מכויל לקצב הדיבור בפועל)
- 🚻 **בחירת מגדר** — נשי / גברי, משפיע על ניסוח הטקסט
- 🎨 **3 סגנונות** — עדין, אנרגטי, עמוק
- 📝 **טקסט טיפולי** — נוצר עם Claude, עם נפילה לתבניות מובנות אם ה-API לא זמין
- 🎙️ **דיבוב קולי** — ElevenLabs TTS, סינתוז מקבילי כדי לעמוד במגבלת הזמן של הפונקציה
- 🔒 **שער סיסמה** — האפליקציה סגורה מאחורי סיסמה (עוגייה ל-30 יום) + הגבלת קצב לפי IP

> ℹ️ **תמונה מרגיעה — בפיתוח.** נקודת הקצה קיימת ועובדת, אבל הקריאה אליה מושבתת כרגע בצד הלקוח.

## 🧠 המודלים

| שלב | מודל | ספק | משתנה סביבה |
|-----|------|-----|--------------|
| טקסט המדיטציה | `claude-sonnet-5` | Anthropic | `ANTHROPIC_API_KEY` |
| דיבוב קולי | `eleven_v3` | ElevenLabs | `ELEVENLABS_API_KEY` |
| תמונה *(מושבת)* | Imagen 3, עם נפילה למודלי תמונה של Gemini | Google | `GEMINI_API_KEY` |

`APP_PASSWORD` — הסיסמה לשער הכניסה.

## 🚀 הרצה מקומית

דרישות: **Node.js v18+** ו-[Vercel CLI](https://vercel.com/docs/cli).

```bash
git clone https://github.com/ShulamitKo/meditation-app.git
cd meditation-app
npm install

# מפתחות
cat > .env.local <<'ENV'
ANTHROPIC_API_KEY=sk-ant-...
ELEVENLABS_API_KEY=...
GEMINI_API_KEY=...
APP_PASSWORD=...
ENV

vercel dev
```

הפרונטאנד הסטטי יושב ב-`public/`, והפונקציות ב-`api/`.

---

## 📡 נקודות קצה

| שיטה | נתיב | מה עושה |
|------|------|---------|
| `POST` | `/api/auth/verify` | אימות הסיסמה, מנפיק עוגיית גישה ל-30 יום |
| `POST` | `/api/meditation/create` | יוצר את טקסט המדיטציה (Claude) |
| `POST` | `/api/meditation/audio` | ממיר את הטקסט ל-MP3 (ElevenLabs) |
| `POST` | `/api/meditation/image` | יוצר תמונה מלווה (מושבת בצד הלקוח) |

**הגבלת קצב** (בזיכרון, לפי IP, מתאפסת ב-cold start): יצירה — 5 בשעה / 10 ביום; אודיו ותמונה — 100 ביום.

## 🏗️ מבנה

```
meditation-app/
├── public/                # הפרונטאנד המוגש בפועל
│   ├── index.html
│   ├── styles.css
│   ├── app.js
│   └── images/
├── api/                   # פונקציות serverless של Vercel
│   ├── auth/verify.js
│   ├── lib/
│   │   ├── auth.js        # שער הסיסמה + חתימת העוגייה
│   │   └── rate-limit.js  # הגבלת קצב לפי IP
│   └── meditation/
│       ├── create.js      # Claude — טקסט
│       ├── audio.js       # ElevenLabs — MP3
│       └── image.js       # Gemini / Imagen — תמונה
├── server/                # ⚠️ שרת Express מדור קודם — לא נפרס, נשמר להתייחסות
└── vercel.json            # maxDuration של 90 שנ' לפונקציות
```

> **שימו לב:** המדיטציות לא נשמרות בשרת — הטקסט וה-MP3 חוזרים ישירות ללקוח.
